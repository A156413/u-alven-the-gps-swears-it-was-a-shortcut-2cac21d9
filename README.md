A deterministic Python program that writes the GPS's one-line excuse for sending the driver down the wrong road to `entry.txt`. The GPS blames the map, not itself: it never argues with maps, it only repeats their lies in a calm, confident voice.

## The entry

> That lake was a shortcut according to the map, and I don't argue with maps — I just repeat their lies in a calm, confident voice.

129 characters (131 bytes UTF-8), within the 200-character limit. One line of plain text, no setup, no dialogue tags — just the excuse itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes `output/entry.txt` (mode 0644) containing exactly the line above.
